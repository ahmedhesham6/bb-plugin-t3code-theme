Makes bb look like T3 Code: its colors, icons, fonts, type sizes, shadows, borders, buttons, inputs, composer, menus, dialogs, spacing and control motion, in light and dark.

## Turn it on

Pick the theme after you install the plugin:

```sh
bb theme set plugin:t3code-theme:t3code
```

You can also pick **T3 Code** in Settings > Appearance or in the Theme Preview dropdown.

## What changes

- Zinc surfaces in light mode, true black in dark mode, and T3 Code's blue for primary buttons, switches, focus rings and the send button.
- T3 Code's system font stack and type sizes.
- Buttons, inputs, the composer, user messages, sidebar rows, menus, popovers, tooltips and dialogs get T3 Code's radius, height, border, shadow and glass effects.
- While the plugin is on, bb's icons change to the Lucide icons T3 Code uses, drawn at T3 Code's stroke width. Brand logos, such as GitHub and Discord, stay the same. The icons change back when you turn the plugin off. The icons follow the plugin, not the theme: they stay Lucide if you pick a different theme while the plugin is on.
- The sidebar and the activity rail get T3 Code's grain texture, with its night-sky art at the top. The send button uses the same art.
- Text and borders use T3 Code's contrast setting at 80%. Menus, dialogs and the composer are solid, as with T3 Code's glass opacity at 100%. Code blocks use 13 px text.
- Buttons scale down a little when you press them. This motion stops when your system asks for reduced motion.

The bb layout stays the same: the same panels, controls and positions.
